# Archived Research Notes

This directory contains exploratory research, implementation notes, and point-in-time audits that informed completed work but are not canonical project timeline or architecture documents.

Archived notes are retained for historical context and review. Current architecture rules belong in [`../engineering/package-architecture.md`](../engineering/package-architecture.md), completed milestones belong in [`../ROADMAP.md`](../ROADMAP.md), and durable engineering specifications belong in the relevant files under [`../engineering/`](../engineering/).

Archived notes must not be treated as current implementation requirements without checking the canonical documents and source code first.
