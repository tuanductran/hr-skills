# Prompt: web-platform and accessibility evaluation

Evaluate a frontend candidate's solution to an interactive component. Separate evidence into semantic structure, browser behavior, responsive design, keyboard/focus management, assistive-technology communication, performance, testing, and maintainability. Distinguish a genuine platform decision from framework-specific syntax. If the candidate proposes React or Next.js, assess the underlying browser and user-experience reasoning before the framework implementation.

Return strengths, risks, unanswered questions, and a seniority-calibrated recommendation. Do not treat visual polish or a list of libraries as proof of accessibility or frontend depth.

References: [MDN Web](https://developer.mozilla.org/en-US/docs/Web), [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/), [Playwright](https://playwright.dev/docs/intro).
