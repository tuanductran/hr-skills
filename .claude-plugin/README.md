# .claude-plugin

This directory contains generated Claude plugin artifacts.

- `marketplace.json` is generated by `bun run sync` from the canonical skill metadata.
- `plugin.json` is generated by `bun run sync`; its `version` follows the root package version and its description follows the current skill count.

Do not hand-edit these manifests as a source of truth. Run `bun run sync`
after changes to skills or package metadata, or use the repository generation
workflow on `main`.
