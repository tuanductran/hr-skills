# hr-skills-build

Internal TypeScript build and service library for the HR Skills monorepo.

This package is private and is not the primary distribution package. It provides the reusable browser-safe and server-compatible library surfaces used by the web application, CLI/build tooling, and the future hosted Phase 8 HTTP adapter.

## Package surfaces

- `hr-skills-build/client` — browser-safe planner, runtime, search, parser, schemas, constants, and shared types.
- `hr-skills-build/server` — registry, filesystem-backed loading, validation, evaluation, build tooling, and server-compatible service functions.
- `hr-skills-build` — backward-compatible alias for the server surface; new application code should prefer `/server`.

The client and server entrypoints share pure implementation through `src/shared/`. The shared layer must remain free of Node.js built-ins. The client bundle and source-level boundary tests enforce this constraint.

## Service layer

The server surface contains the versioned Phase 8 service contracts and implementations for:

- health and readiness
- version information
- registry search
- planning
- workflow runtime
- evaluation

The HTTP contract is documented in `docs/engineering/platform-integration.md`. HTTP authentication, rate limiting, request IDs, provider-specific deployment concerns, and transport serialization belong to the hosted adapter, not this package.

## Build and development

Requires [Bun](https://bun.sh). Run from the monorepo root:

```bash
bun install
bun run build
bun run test
bun run typecheck
bun run validate
```

Package-local commands:

```bash
bun run build
bun run test
bun run typecheck
bun run validate
bun run sync
bun run matrix
bun run docs-data
bun run verify-client-bundle
```

## Generated documentation

Public API documentation is generated by `packages/hr-skills-tsdoc`. When public service or package surfaces change, regenerate and verify the API reference with `bun run api-docs` and `bun run api-docs:check`.

## Source layout

| Folder | Purpose |
| --- | --- |
| `src/shared/` | Pure shared implementation used by both public surfaces |
| `src/client/` | Browser-safe exports and client-specific additions |
| `src/server/` | Server/build/evaluation/service implementations |
| `test/` | Unit and architecture-boundary tests |

See `docs/engineering/package-architecture.md` for the canonical import rules.
